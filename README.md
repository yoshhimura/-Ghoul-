# Проект "Калькулятор"

[![Python Version](https://img.shields.io/badge/python-3.9%2B-blue)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Простой консольный калькулятор на Python, выполняющий основные арифметические операции. Проект создан в учебных целях для освоения принципов чистого кода, тестирования и документирования.

## 🚀 Возможности

- ➕ Сложение (`add`)
- ➖ Вычитание (`subtract`)
- ✖️ Умножение (`multiply`)
- ➗ Деление (`divide`)
- ⚡ Возведение в степень (`power`)
